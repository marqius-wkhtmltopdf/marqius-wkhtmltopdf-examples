# java-wkhtmltopdf-wrapper with Marqius

Keep the existing library and HTML. Configure the executable supplied by [Marqius wkhtmltopdf](https://marqius.com/wkhtmltopdf/).

Language: Java. The sample files are `pom.xml`, `src/main/java/Smoke.java`. Framework examples run inside an existing application with the named package installed; the CI workflow creates a fresh application to exercise them.

Read the complete [developer-manual chapter](https://marqius.com/download/developer-manual.pdf#page=38) for installation, before/after comparison and deployment notes. The root README lists the exact example commands and dependencies.

Use a representative document with your own fonts and compare the PDF before changing production. These examples use static sample HTML, not untrusted user content.
