# django-wkhtmltopdf with Marqius

Keep the existing library and HTML. Configure the executable supplied by [Marqius wkhtmltopdf](https://marqius.com/wkhtmltopdf/).

Language: Python / Django. The sample files are `render.py`. Framework examples run inside an existing application with the named package installed; the CI workflow creates a fresh application to exercise them.

Read the complete [developer-manual chapter](https://marqius.com/download/developer-manual.pdf#page=13) for installation, before/after comparison and deployment notes. The root README lists the exact example commands and dependencies.

Use a representative document with your own fonts and compare the PDF before changing production. These examples use static sample HTML, not untrusted user content.
